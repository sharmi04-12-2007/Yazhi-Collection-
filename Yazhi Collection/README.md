## 🌸 About

Yazhi Collection is a full-featured boutique website built with pure **HTML5, CSS3, and JavaScript** — no frameworks, no build tools. It simulates a complete e-commerce experience using `localStorage` as a shared data store.

---

## 🚀 How to Open

1. Double-click **`index.html`** in your file browser, **or**
2. Right-click any `.html` file → *Open with* → your browser (Chrome recommended)

> **No server or installation needed.** Everything runs locally in the browser.
